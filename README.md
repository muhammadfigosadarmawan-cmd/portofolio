# Portofolio Muhammad Figo Darmawan — Latihan Individu 3

## Isi proyek
- `index.html` — markup halaman dan penggunaan utility Tailwind CSS.
- `css/style.css` — desain tambahan, layout khusus, animasi, responsif, dan tema terang.
- `css/loader.css` — gaya loading screen.
- `js/main.js` — menu mobile, dark/light mode, animasi teks, filter proyek, navigasi aktif, tombol kembali ke atas, dan formulir kontak.
- `js/loader.js` — progress loading.
- `images/foto-figo.jpg` — letakkan foto profil di sini.
- `cv-figo.pdf` — contoh CV awal yang harus diperbarui.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Jalankan `index.html` menggunakan Live Server.
4. Koneksi internet diperlukan karena Tailwind CSS, Google Fonts, dan ikon/asset eksternal (jika ditambahkan) dimuat melalui CDN.

## Checklist sebelum dikumpulkan
1. Ganti `EMAIL_KAMU` di `index.html` dan `js/main.js` dengan email aktif.
2. Ganti tautan GitHub dan LinkedIn dengan akun asli.
3. Tambahkan foto di `images/foto-figo.jpg`.
4. Perbarui `cv-figo.pdf` dengan data kontak dan riwayat asli.
5. Ganti placeholder sertifikat dengan sertifikat yang benar-benar dimiliki atau hapus jika belum ada.
6. Ganti tautan demo/repository proyek dengan tautan yang valid.
7. Tambahkan tahun pendidikan SMA/SMK, organisasi, magang, atau pengalaman lain yang benar.
8. Form kontak versi ini menggunakan `mailto:`; belum terhubung ke backend Laravel/MySQL dan tidak menyimpan pesan di database.

## Catatan teknologi
Tugas ini masih berupa frontend statis dengan HTML, Tailwind CSS CDN, CSS, dan JavaScript. Laravel/MySQL baru direncanakan untuk tahap API berikutnya, sesuai deskripsi tugas.
